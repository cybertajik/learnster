# Lernster - Modern Spanish Vocabulary & Sentence Learning App

**Lernster** is a modern, responsive web application for learning Spanish vocabulary and conversational sentences across A1, A2, B1, and B2 levels.

## Key Features
- **1,200 Vocabulary Words** (300 A1, 300 A2, 300 B1, 300 B2) + **710 Sentences**.
- **Interactive Boy Mascot**: Dynamic expression shifts (`happy`, `sad`, `cry`, `bored`, `logo`) reacting to user performance and idle timers.
- **Audio Pronunciation**: Native Spanish Web Speech synthesis with customizable voice controls.
- **Spaced Repetition & Level Filters**: Seamlessly filter flashcards by `A1`, `A2`, `B1`, `B2`, or `Sentences`.
- **Milestone Celebrations**: Falling confetti at 50/150/250/350/450 correct answers and grand fireworks at 500.
- **Dark & Bright Mode**: Full theme customization in user settings.
- **Supabase Ready**: Prepared for cloud authentication and database synchronization.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
